# 远程文件管理与文件操作审计有什么不同？

远程文件管理用于操作目标电脑上的文件，文件操作审计用于查询已经记录的文件行为。洞察眼MIT系统提供两类能力：前者帮助 IT 下发配置、取回日志，后者帮助管理人员核查某份资料何时被操作。两者的目的和使用条件不同。

## 按任务选择功能

| 任务 | 应使用的能力 |
| --- | --- |
| 将配置文件放到目标电脑 | 远程文件管理 |
| 取回排障日志 | 远程文件管理 |
| 核查资料何时被复制或删除 | 文件操作审计 |
| 删除确认不再需要的终端文件 | 远程文件管理，并核对目标路径 |

## 文件操作前先核对目标

远程浏览、上传、下载或删除发生在目标电脑上，需要正常通信及文件访问条件。执行前确认电脑、目录和文件名，操作后查看结果。不能把“浏览到了文件”理解成已完成备份，也不能把删除操作当作可随时撤销。

## 查历史时注意数据来源

审计查询依赖当时监测到且已经保留的记录，不需要将“现在文件是否还存在”与“以前是否记录过该操作”混为一谈。文件记录也不自动提供全部正文、所有历史内容或完整外发证明。
