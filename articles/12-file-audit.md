# 文件操作审计怎样帮助核查资料使用过程？

文件操作审计帮助查询监测范围内资料何时被打开、修改、复制、移动、重命名或删除。洞察眼MIT系统将已采集的时间、电脑、用户和路径等线索用于查询，适合围绕具体资料或异常时段开展复核。

## 先确定文件和时间范围

同名文件可能位于不同目录，核查时应结合路径、电脑和操作时间。若要了解某次集中复制，可以先查看相关时间段的操作，再区分正常整理、任务处理和需要进一步确认的情况。操作名称本身不能解释业务目的。

## 与其他记录怎样对照

可继续查询相近时段的 USB 插拔、打印、剪贴板摘要以及已保存画面。不同记录能补充不同问题：USB 记录反映设备接入，打印记录反映任务信息，画面反映采集时刻或已录制过程。时间接近只是核查起点，不能自动证明彼此存在因果关系。

## 能否据此证明资料已经外发

文件复制或移动不单独证明外发，更不能确定外部接收人。系统提供操作线索，最终判断应结合实际业务材料。没有监测到或未保存的行为也不能从现有记录中补全，文件审计不等于透明加密或文件正文备份。
