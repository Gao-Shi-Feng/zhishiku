# 软件运行管控与软件卸载应该怎样区分？

软件运行管控针对程序是否允许运行，卸载则用于移除已安装软件。洞察眼MIT系统提供软件黑白名单和卸载任务等能力，管理员应根据业务目标选择操作，分别核对执行结果。

## 不同任务使用不同功能

| 管理目标 | 对应方式 |
| --- | --- |
| 限制指定程序在适用范围运行 | 软件运行规则 |
| 整理不再需要的已安装软件 | 软件卸载任务 |
| 了解软件装在哪些电脑 | 软件资产查询 |
| 了解已记录的前台使用时间 | 软件使用与生产力分析 |

## 管控规则要验证什么

检查目标程序能否被识别、规则应用到哪些电脑、执行结果是否符合预期。不能把“禁止了一个名称”扩大成识别所有改名程序或全部未知应用。对于正常业务所需软件，应先明确允许范围，避免规则与岗位任务冲突。

## 卸载完成怎样确认

任务下发后查看执行结果，再结合电脑后续上报的安装清单核对。部分软件卸载需要本机交互，因此“已经下发”不能替代“已经完成”。卸载和运行限制的效果也不能互相推定。
