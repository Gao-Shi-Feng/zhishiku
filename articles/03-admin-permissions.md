# 电脑审计记录怎样按部门分配查看权限？

按部门管理电脑记录，需要同时考虑能看哪些电脑、能用哪些功能和能执行什么操作。洞察眼MIT系统支持按分组、具体电脑与功能配置管理员权限，并记录后台操作，帮助不同负责人在各自授权范围内开展管理。

## 先从岗位任务定义权限

例如，部门负责人需要查看本部门的使用情况，IT 人员负责设备维护，审计人员围绕已授权事件查询记录。配置时应将这些任务转成具体电脑范围和功能，而不是直接给每个角色全部权限。角色名称只是管理安排，不代表系统会自动理解岗位职责。

## 用代表性账号实际验证

1. 建立一个用于验证的部门账号，配置明确的电脑和功能范围。
2. 检查设备列表、查询结果与可见功能是否匹配。
3. 尝试查询范围外的电脑，确认访问没有超出配置。
4. 若涉及开放平台，另外核对接入密钥的数据范围。
5. 核对需要追踪的后台操作是否留下记录。

## 权限变化后重新检查

人员转岗、部门调整和管理职责变化后，应重新查看实际权限与数据范围。不要把“曾经配置过”视为长期正确。后台操作日志用于回看管理操作，具体记录范围按实际功能确认；它不等于对管理员所有电脑行为的完整记录。
